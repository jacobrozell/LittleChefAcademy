# Mac's Little Chefs Academy

One-page site for kids cooking / nutrition classes. Public brand is **Mac's Little Chefs Academy**, under **McKelvey's Nutrition Services** LLC.

**Preview:** https://jacobrozell.github.io/LittleChefAcademy/  
GitHub: [`jacobrozell/LittleChefAcademy`](https://github.com/jacobrozell/LittleChefAcademy) (folder is `MacsLittleChefsAcademy`).

**Status:** Mac loved the preview. Waiting on logo, `macslittlechef.com` vs a new URL, Squarespace DNS access, and the signup email. Long-term host is Cloudflare Pages so the GitHub repo can go private.

Photos and reviews are placeholders. The form does not email Mac yet.

## Local

```sh
python3 -m http.server 5173 --directory site
```

Open http://127.0.0.1:5173
